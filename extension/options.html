Whitelist Filters

Downloads matching whitelisted URLs or file extensions are always intercepted by Bengal DM.

Whitelisted URLs & Domains

Always capture downloads originating from these websites or URL patterns (e.g. github.com, releases.ubuntu.com).

Whitelisted File Extensions

Always capture downloads with these specific extensions (e.g. .iso, .zip, .tar.gz).

Blacklist Filters

Downloads matching blacklisted URLs or file extensions are skipped and left to the browser's native downloader.

Blacklisted URLs & Domains

Never intercept downloads from these websites (e.g. bank.com, internal-corp.net).

Blacklisted File Extensions

Never intercept files with these extensions (e.g. .jpg, .pdf, .txt).
